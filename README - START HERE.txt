    Welcome! Follow these two steps to get started:


    STEP 1 — INSTALL (first time only)
    ───────────────────────────────────

    On Windows:   Double-click  INSTALL.bat
    On Mac:       Double-click  install_mac.command

    This will:
    ✓ Install Python (if you don't have it)
    ✓ Install the required software
    ✓ Ask you to paste the API key you were given
    ✓ Create a shortcut on your Desktop

    It takes about 2-5 minutes.


    STEP 2 — RUN THE APP
    ───────────────────────────────────

    On Windows:   Double-click "Astra Mailer" on your Desktop
                  — or double-click launch_astra_mailer.bat

    On Mac:       Double-click "Astra Mailer" on your Desktop
                  (first time: right-click → Open → click "Open")


    HOW TO USE THE APP
    ───────────────────────────────────
    Tab 1 (Setup):    Your API key and email template are here
    Tab 2 (Data):     Upload your student spreadsheet (.csv or .xlsx)
    Tab 3 (Generate): Click "Generate All Emails" and watch it work
    Tab 4 (Export):   Review emails, copy them, or export to a file


    NEED HELP?
    ───────────────────────────────────

    Windows:
    • If INSTALL.bat won't run: Right-click → "Run as administrator"
    • If a blue warning appears: Click "More info" → "Run anyway"

    Mac:
    • If install_mac.command won't open: Right-click → Open → "Open"
    • If you see "permission denied" in Terminal, run:
        chmod +x install_mac.command
      then try again.

    Both:
    • If the app won't start: Run the installer again
    • For anything else, contact the person who sent you this!
